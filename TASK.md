# Health Automation Engineer Take-Home Technical Task

Here you will find a simple application. Take some time to familiarise yourself with all the components and get the application running locally.

## Setting the scene

Your colleague has been combining PDFs by hand. You initially wrote a little python script that would take a directory of PDFs and stitch them together into one PDF, however your colleague finds the user experience a little clunky.

Another of your colleagues has built this application which organises PDFs into projects and you decide you can build the combination functionality on top of it.

## What you need to do to the codebase

Please make additions to this code to provide the stitch-together functionality.

Ideally the stitched document should be stored and available to retrieve.

At minimum, there should be a button 'Combine PDFs' or similar.

### Other points

Please use whatever tools you have at your disposal to solve this problem - whatever you could conceivably use in a workplace setting. Do make sure you know what everything is doing and how you would go about developing similar features as you will be asked about this during the interview.

Try to avoid changing existing code; it should suffice to add code only.

We expect, once you have everything up and running, this should take no more than 2 hours to complete.


## What you need to prepare before the interview

Please put together a short and simple presentation on what you would do to productionise this application; how would this be distributed to the people? What resources would you use? It may help (but is not necessary) to include an architecture diagram.

This should be no more than 5 slides.

## DON'T PANIC
I hope you have fun with this task and it allows you to learn something new. There is no expectation that you should already know the frameworks employed here
